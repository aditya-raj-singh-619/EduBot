# BCC — Basic Computer Course

**Revision:** 2 | **Effective:** 01 June 2019 | **Annexure-2**
**Issued by:** National Institute of Electronics and Information Technology (NIELIT)

---

## Objective

The course is designed to aim at imparting a basic level appreciation
programme for the common man. After completing the course, the incumbent
will be able to:

- Use the computer for basic purposes of preparing personal/business letters
- Create data and perform basic operations with data using spreadsheet
- Create and use basic presentations
- View information on the Internet (the web)
- Create an email account and send/receive emails
- Use Digital Financial Services
- Use Social Media, e-Governance and their usage

The course allows a common man or housewife to be part of the computer
users' community by making them digitally literate. This helps small
business communities and housewives maintain their small accounts using
computers and engage with Information Technology.

The module on financial literacy enables individuals to understand various
financial services and become aware of various Government of India schemes.

## Duration

**36 Hours** — Theory: 14 hrs + Practical: 22 hrs

This course can also be offered as a 6 days full-time intensive course.

## Eligibility

No minimum qualification is required for applying and appearing for the
examination in Basic Computer Course (BCC).

### Chapter 1 — Introduction to Computer
Computer and Latest IT gadgets (computers & their applications, IT gadgets);
Basics of Hardware and Software — CPU, Input devices, Output devices,
Computer Memory & storage, connecting Keyboard/Mouse/Monitor/Printer to CPU;
Application Software, Systems Software, Mobile Apps.
**Outcome:** Awareness of computers/IT gadgets and applications; familiarity
with input, output, hardware components and storage devices; understand how
peripherals connect to CPU; know software types for computer and mobile.

### Chapter 2 — Introduction to Operating System
Operating Systems for Desktop/Laptop and for Mobile/Tablets; User Interface
(Task Bar, Icons & Shortcuts, Running an Application); OS simple settings
(mouse use, system date/time, display properties, add/remove
programs/features); File and Folder Management; Types of file extensions.
**Outcome:** Acquainted with OS and its applications for desktop and mobile;
identify screen components and modify display settings; add/remove programs;
manage files/folders; aware of file extensions.

### Chapter 3 — Word Processing
Word Processing Basics (opening the package, Title/Menu Bar, Toolbars &
Sidebar, creating a document); Opening/Closing Documents (save/save as,
help, page setup, print preview, printing, saving as PDF); Text Creation &
Manipulation (editing, selection, cut/copy/paste, font/color/style/size,
alignment, undo/redo, autocorrect/spelling/grammar, find & replace);
Formatting (indentation, bullets/numbering, change case, header & footer);
Table Manipulation (insert/draw, resize, alignment, insert/delete/merge/
split cells, border & shading); Shortcut Keys.
**Outcome:** Basic knowledge of word processing; open/save/print documents
including PDFs; create and format documents, insert headers/footers, find &
correct text, and work with tables.

### Chapter 4 — Working with Spreadsheet
Elements of Spread Sheet (creating, cell address, entering data, page setup,
printing, saving, opening/closing); Manipulation of Cells & Worksheet
(editing content, formatting, cut/copy/paste special, resizing, insert/
delete rows-columns, AutoFill); Formulas, Functions and Charts (basic
arithmetic formulas, AutoSum, SUM/COUNT/MAX/MIN/AVERAGE).
**Outcome:** Basic knowledge of spreadsheets; open/save/print a sheet; create
worksheets and insert/edit data; manage cell heights and AutoFill;
insert/delete rows-columns; apply basic formulas and functions.

### Chapter 5 — Creating Presentations
Creation of Presentation (template-based, blank, inserting/editing text,
inserting/deleting slides, saving); Manipulating Slides (tables, clip art,
other objects, resizing/scaling); Presentation of Slides (set-up, running
slide show, transitions & timings, automating, printing slides & handouts).
**Outcome:** Basic knowledge of presentations; open/save and print slides and
handouts; manipulate slides with pictures, objects and formatting; run slide
shows with transitions.

### Chapter 6 — Introduction to Network & Internet
Basics of Computer Networks (LAN, WAN); Internet (concept of Internet & WWW,
applications, website address & URL, ISP & its role, connection modes —
Hotspot/Wi-Fi/LAN/Broadband/USB Tethering); Popular Web Browsers; Exploring
the Internet (surfing, search engines, searching, downloading and printing
web pages).
**Outcome:** Knowledge of network types; overview of Internet and browsers;
connect via various modes/devices; search, download and print web content.

### Chapter 7 — E-mail, Social Networking and e-Governance Services
Structure of E-mail; Using E-mails (opening account, inbox/outbox,
composing/sending, replying, forwarding); Social Networking & e-Commerce
(Facebook/Twitter/LinkedIn/Instagram, Instant Messaging — WhatsApp/Messenger/
Telegram, Netiquettes); e-Governance Services overview (Railway Reservation,
Passport, eHospital/ORS); UMANG App; Digital Locker.
**Outcome:** Create and use email; use social networking, instant messaging
and blogs; access e-Governance, e-Commerce and mobile apps.

### Chapter 8 — Digital Financial Tools and Applications
Digital Financial Tools (OTP, QR Code, UPI, AEPS, USSD, Credit/Debit Card,
eWallet, PoS); Internet Banking (NEFT, RTGS, IMPS); Online Bill Payment.
**Outcome:** Know digital financial tools and internet banking modes; use
e-Governance/e-Commerce/mobile apps; use Digital Locker to store documents.

## Practical Software Note

For practical purposes, the latest version of Free Open Source Ubuntu &
LibreOffice may be used.
