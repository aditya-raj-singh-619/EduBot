## About the Course

'A' Level (IT) Revision 5.1 is the fifth revised version of the DOEACC 'A' Level syllabus
in Information Technology, effective from July 2022. The syllabus is designed to equip
students with skills required for various IT job roles through a structured combination of
core and specialized modules.

---

## Course Structure

'A' Level consists of 10 modules: 8 mandatory core modules + 1 specialized area (2 modules
chosen from one of 5 groups).

**Mandatory Core Modules (8):**

| Module Code | Module Name | Theory (hrs) | Practical (hrs) | Total (hrs) |
|---|---|---|---|---|
| A1-R5.1 | Information Technology Tools and Network Basics | 48 | 72 | 120 |
| A2-R5.1 | Web Designing & Publishing | 48 | 72 | 120 |
| A3-R5.1 | Programming and Problem Solving through Python | 48 | 72 | 120 |
| A4-R5.1 | Internet of Things and its Applications | 48 | 72 | 120 |
| A5-R5.1 | Data Structure Through Object Oriented Programming Language | 48 | 72 | 120 |
| A6-R5.1 | Computer Organization and Operating System | 48 | 72 | 120 |
| A7-R5.1 | Database Technologies | 48 | 72 | 120 |
| A8-R5.1 | Systems Analysis, Design and Testing | 48 | 72 | 120 |

**Note:** A1 to A4 (modules 1–4) are the same as O Level modules M1 to M4 (Revision 5.1).
Candidates who have passed 'O' Level (IT) are exempted from A1-R5.1, A2-R5.1,
A3-R5.1 and A4-R5.1.

**Specialized Areas (Choose ONE group — both modules in the group are mandatory):**

| Group | Area | Module 9 (A9.x-R5.1) | Module 10 (A10.x-R5.1) |
|---|---|---|---|
| 1 | Data Analytics | A9.1: Big Data Analytics Using Hadoop | A10.1: Data Science Using Python |
| 2 | Web Application Development | A9.2: Web Application Using PHP | A10.2: Full Stack Web Development Using MVC Framework |
| 3 | Information Security | A9.3: Network Management | A10.3: Information Security Management |
| 4 | Internet of Things | A9.4: Internet of Things (IoT): A Practical Approach | A10.4: Internet of Things (IoT) Using Raspberry Pi |
| 5 | Artificial Intelligence | A9.5: Artificial Intelligence Concepts and R Programming | A10.5: Machine Learning Using Python |

- Minimum period: 1.5 years (fresh candidates)

**Semester Sequence (Fresh Candidates):**

| Semester | Modules |
|---|---|
| Semester I | A1-R5.1, A2-R5.1, A5-R5.1, A6-R5.1 + Practicals APR-I to APR-V |

| Semester III | A8-R5.1, A10.x-R5.1 + Major Project (PJ-II: 360 hrs, specialized area) |

## Credit Scheme

Based on NCVET guidelines (1 credit = 30 hours):
- Each of the 10 modules: 4 credits each
- Mini Project (PJ-I): 2 credits
- Major Project (PJ-II): 12 credits
- **Total Credits: 54**

---

## Examination Pattern

| Mode | Duration | Questions | Max Marks | Min Pass | Weightage |
|---|---|---|---|---|---|
| Theory (Online/OMR) | 2 Hours | 100 MCQ | 100 | 33% | 60% |
| Practical (Demo + Viva) | 3 Hours | 3-4 | Lab: 80, Viva: 20 | 33% | 40% |

Minimum Pass: 50% of total weightage (Theory + Practical) in each module.

---

## Projects

### Mini Project (PJ-I) — 60 hours
Same guidelines as 'O' Level project. Submitted as part of Semester II.

### Major Project (PJ-II) — 360 hours
- Mandatory to qualify 'A' Level (IT)
- Must be based on the specialized area chosen
- Carries 300 marks (80% project evaluation + 20% viva-voce)
- Can be submitted only after clearing 5 papers of 'A' Level and appearing in both
  modules of the chosen specialized area
- Must be original; student develops browser-based, mobile-based or client-server
  application in the specialized area domain
- Submitted with one hard copy + soft copy on Optical Drive (~50 pages excluding code)

## Module Syllabi (Mandatory Modules)

### A1 to A4 — Same as O Level Modules M1 to M4
A1-R5.1 to A4-R5.1 cover the same syllabus as the 'O' Level modules M1-R5.1 to
M4-R5.1 respectively (IT Tools & Network Basics, Web Designing & Publishing,
Programming through Python, and IoT). Refer to the O Level syllabus document for
full details.

---

### A5-R5.1 — Data Structure Through Object Oriented Programming Language
**Duration:** 120 hrs (Theory: 48 hrs + Practical: 72 hrs)
**Topics:** Data structures (arrays, linked lists, stacks, queues, trees, graphs, sorting and
searching algorithms), Object Oriented Programming concepts (classes, objects,
inheritance, polymorphism, encapsulation, abstraction), implementation in an OOP
language.

---

### A6-R5.1 — Computer Organization and Operating System
**Duration:** 120 hrs (Theory: 48 hrs + Practical: 72 hrs)
**Topics:** Computer Organization (digital logic, memory systems, processor architecture,
I/O systems, buses), Operating Systems (process management, memory management,
file systems, I/O management, security, distributed systems).

---

### A7-R5.1 — Database Technologies
**Duration:** 120 hrs (Theory: 48 hrs + Practical: 72 hrs)
**Topics:** Database concepts, Relational Model, SQL (DDL, DML, DCL, TCL), ER
modelling, Normalization, Transactions, Concurrency Control, NoSQL concepts,
Database Administration basics.

---

### A8-R5.1 — Systems Analysis, Design and Testing
**Duration:** 120 hrs (Theory: 48 hrs + Practical: 72 hrs)
**Topics:** Software Development Life Cycle (SDLC), Requirements Analysis, System
Design (HLD, LLD), UML diagrams, Software Testing (unit, integration, system,
acceptance testing), Software Project Management, Software Quality Assurance.

---

## Specialized Area Modules

### Data Analytics Group

**A9.1-R5.1 — Big Data Analytics Using Hadoop**
Duration: 120 hrs | Topics: Big Data concepts, Hadoop ecosystem (HDFS, MapReduce,
YARN, Hive, Pig, HBase, Spark), data ingestion tools (Sqoop, Flume), analytics
workflows.

**A10.1-R5.1 — Data Science Using Python**
Duration: 120 hrs | Topics: Data Science workflow, Python for data analysis (NumPy,
Pandas, Matplotlib, Seaborn), statistical methods, machine learning basics, data
visualization, real-world data science projects.

---

### Web Application Development Group

**A9.2-R5.1 — Web Application Using PHP**
Duration: 120 hrs | Topics: PHP fundamentals, server-side scripting, MySQL integration,
sessions and cookies, forms processing, MVC basics, security in PHP applications.

**A10.2-R5.1 — Full Stack Web Development Using MVC Framework**
Duration: 120 hrs | Topics: Full Stack development concepts, MVC architecture, frontend
(HTML5, CSS3, JavaScript, Bootstrap), backend framework (Laravel or equivalent),
RESTful APIs, database integration, deployment.

---

### Information Security Group

**A9.3-R5.1 — Network Management**
Duration: 120 hrs | Topics: Network protocols (TCP/IP, OSI), network architecture,
routing and switching, network services (DNS, DHCP, HTTP), network monitoring and
management tools, troubleshooting.

**A10.3-R5.1 — Information Security Management**
Duration: 120 hrs | Topics: Information security concepts, cryptography, PKI, network
security, firewalls, IDS/IPS, vulnerability assessment, risk management, ISO 27001,
cyber laws.

---

### Internet of Things Group

**A9.4-R5.1 — Internet of Things (IoT): A Practical Approach**
Duration: 120 hrs | Topics: Advanced IoT architectures, communication protocols
(MQTT, CoAP, Zigbee, Z-Wave), cloud platforms for IoT, IoT data analytics, industry
applications.

**A10.4-R5.1 — Internet of Things (IoT) Using Raspberry Pi**
Duration: 120 hrs | Topics: Raspberry Pi hardware and OS, GPIO programming, Python
for Raspberry Pi, interfacing sensors and actuators, connecting to cloud, building
Raspberry Pi based IoT applications.

---

### Artificial Intelligence Group

**A9.5-R5.1 — Artificial Intelligence Concepts and R Programming**
Duration: 120 hrs | Topics: AI fundamentals, search algorithms, knowledge representation,
expert systems, natural language processing basics, R programming language for
statistical computing and AI.

**A10.5-R5.1 — Machine Learning Using Python**
Duration: 120 hrs | Topics: Machine learning concepts and types (supervised, unsupervised,
reinforcement), scikit-learn, regression, classification, clustering, neural network basics,
model evaluation, real-world ML projects using Python.
